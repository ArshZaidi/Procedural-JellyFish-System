A procedurally generated, mathematically animated 3D jellyfish system built entirely in Desmos 3D using implicit surfaces, trigonometric functions, constraints, and HSV color mapping.


Overview
This project explores procedural mathematical modelling by generating an animated 3D jellyfish entirely from equations.
Unlike conventional 3D modelling workflows, this project contains no meshes, no imported models, and no external 3D assets. Every component of the jellyfish—including its bell, oral arms, tentacles, pulsation, and colour mapping—is defined mathematically.
The project demonstrates how mathematics can be used as a medium for procedural graphics and artistic visualization.

Motivation
The objective of this project was to explore whether complex animated biological structures could be represented entirely through mathematical equations.
By combining implicit surfaces, procedural animation, and mathematical constraints, this project demonstrates an alternative approach to 3D modelling that relies solely on mathematics rather than traditional mesh-based workflows.
